# 反向连接
本mod仅适用于有任一房客有可在公网被ping到的ipv6，房主有ipv6但不可在公网被ping到的情况。

本mod通过反向建立一个转发通道来建立联机。非代理房客因为数据包会被转发两次，会带来更高的延迟。

可以在网站[测试ping](https://www.itdog.cn/ping_ipv6/)测试ipv6是否可以在公网被ping到。

路由器提供的ipv6网络一般不可在公网被ping到。可以尝试手机热点。根据作者的经验，联通、电信的卡开启的热点一般可以。让你的朋友们都试试自己的网络，如果有一个人的ipv6可以被ping到，那你们就可以尝试用本mod开始联机了！

## 使用方法
1. 房主将游戏**对局域网开放**
2. 有可在公网ping到的ipv6的房客(简称代理房客)点击**多人游戏-直接连接-开启代理服务**，填写并记住主服务器连接端口(服务器连接)和用户连接端口(其他玩家连接)，点击"开启"按钮，提示"已开启服务"，进行下一步。可点击返回。
3. 代理房客将自身的ipv6地址和**主服务器连接端口**发送给房主
4. 房主打开**通过代理服务器反向连接**按钮，填写代理房客的`[ipv6地址]:主服务器连接端口`
5. 房主点击连接按钮，若显示"已连接到代理服务器"，则成功建立反向连接。
6. 连接成功后，代理房客使用`[::1]:用户连接端口`(回环地址)进入多人游戏。其他房客使用`[代理房客ipv6地址]:用户连接端口`进入多人游戏。

**注意：一定不要将ipv6地址分享给任何你不信任的人！！！！**
